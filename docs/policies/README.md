# Policies

Fourteen controlled policy documents, all currently **DRAFT** (version 0.1, unapproved). The authoritative index — status, owner, and review date per policy — is [`../compliance/policy-index.md`](../compliance/policy-index.md).

Each policy carries its own front block (status, owner, approver, version, dates), numbered requirements, exceptions routing via the [exceptions register](../compliance/exceptions-register.md), evidence references, and related control IDs from the [control matrix](../compliance/control-matrix.md).

Policies are approved at a phase gate, not edited into approval: a policy leaves DRAFT only with a named approver and an effective date, recorded in the policy-index.
